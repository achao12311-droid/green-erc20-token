# 模型驗證

模型服務在 `ai/`。它現在不會下載權重，也不需要 GPU 才能啟動。

## 目前真正會做的事

- 用 SHA-256 判斷兩個檔案位元組是否完全相同。它不能判斷重新壓縮或修改過的影片。
- 完全相同的 SHA-256 回 `rejected`。近似重複改為 `pending_review`，不會自動退件。畫面雜湊仍是 `not_configured`。
- 動作檢查使用 ONNX Model Zoo 的 MobileNetV2（Apache-2.0，約 14 MB）。它看影片影格裡的物件。看到與申報行為相符的物件就自動核准，沒有相符、檔案重複或影片打不開就拒絕。沒有人工審核這一步。
- 這個模型不能證明影片是真的，也不能證明人真的做了那件事。它只根據畫面裡的物件決定給不給獎勵。

## 故意不做的事

- 不把模型分數說成機率。
- 不宣稱可以證明影片是真的或是生成的。
- 不因為模型結果自動鑄 ECO。`approved` 只能由人工審核產生。
- 不把提交的影片自動拿去訓練。要另有授權。

近似重複需要畫面雜湊與 FFmpeg。這兩項沒有安裝，所以介面會明說 `not_configured`，不會用 SHA-256 不同來假裝是不同的真實活動。

之後若要加入 VideoMAE、CLIP 或其他模型，只能替換 `ai/inference/adapters.py`，並在文件記下模型名稱、版本、授權與硬體需求。大檔權重不能在安裝時自動下載。
