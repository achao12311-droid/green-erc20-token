# 代幣規則

## 已確定的部分

| 項目 | 值 |
| --- | --- |
| 名稱 | Green Eco Token |
| 符號 | ECO |
| 小數 | 18 |
| 上限 | 1,000,000 ECO |
| 網路 | 先使用 Ethereum Sepolia，鏈 ID 11155111 |

ECO 是部署在以太坊上的 ERC-20。以太坊自己的權益證明保護的是以太坊網路。鎖定 ECO 只是這個應用程式的功能，不是成為以太坊驗證者，也不會產生利息或年化報酬。

新的 ECO 只能由被授權的證明人簽名之後鑄出。簽名包含收款地址、提交 ID、ECO 數量（wei）、nonce、期限、紀錄雜湊、合約與鏈 ID。同一筆提交與同一個證明人的同一個 nonce 都不能再用。超過上限的鑄幣會失敗。

## Eco Points

Eco Points 是內部記分，不是碳排、垃圾重量或任何科學測量。

開發用的分數在 `records/reward-policy.json`：

| 活動 | 分數 |
| --- | --- |
| PICK_UP_LITTER | 50 |
| RECYCLING | 30 |
| PARK_CLEANUP | 100 |
| BEACH_CLEANUP | 150 |
| TREE_PLANTING | 200 |
| ENVIRONMENTAL_EVENT | 300 |

這些數字是占位，不是最終規則。政策有版本號。

## 獎勵

政策版本 2。1 點等於 0.01 ECO。這是獎勵表，不是碳排或垃圾重量。

| 活動 | ECO |
| --- | --- |
| 撿垃圾 | 0.5 |
| 回收 | 0.3 |
| 公園清理 | 1 |
| 海灘清理 | 1.5 |
| 種樹 | 2 |
| 環境活動 | 3 |

審核通過後，後端會準備這個數量。真正增加餘額仍要證明人簽名並送上鏈。模型服務不能持有那把鑰匙。

## 質押與抽獎券

質押鎖定的 ECO 可以原數取回，沒有利息。

抽獎券是用 ECO 買的。票價由每一場活動設定。活動取消時退票。活動完成後票錢留給主辦者，參加者不能把票錢領回。CS2 皮膚不在鏈上發放，由主辦者交給得主。公開網路在 Chainlink VRF 接上之前不能開獎。測試用隨機來源只存在 `contracts/test/`。

## 供給用盡

總量到達 1,000,000 ECO 之後，再合法的簽名也無法鑄幣。合約不會自動提高上限。
