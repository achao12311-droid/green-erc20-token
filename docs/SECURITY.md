# 安全說明

這份文件不是獨立安全稽核，也不能把專案說成已可上主網。

## 合約

- 鑄幣必須有授權證明人的 EIP-712 簽名。
- 提交 ID 與 nonce 都會被消耗。
- 簽名有期限，並綁定鏈 ID 與合約。
- 供給有上限。
- 鑄幣可以暫停，轉帳不能暫停，避免管理員凍結餘額。
- 質押先改帳再轉幣，並使用重入保護。多轉進質押合約、卻沒有經由 `stake` 的餘額，只能由管理員取回超出記帳的部分。
- 活動隨機數若沒有設定，關閉活動會整筆交易失敗，不會用假的隨機數抽出贏家。
- 測試隨機合約在 `contracts/test/`，部署腳本不會使用它。

證明人仍然受信任：政策換算一旦確認，證明人可以簽到上限為止的數量。這不是多簽。

## 後端

- 登入使用錢包簽名與一次性 nonce。
- Cookie 是 HttpOnly、SameSite=Strict。正式環境若仍使用預設 `SESSION_SECRET`，程序會拒絕啟動。
- 有每分鐘速率限制與輸入檢查。
- 獎勵金額不信任前端。
- 管理員名單來自環境變數，審核會留紀錄。
- 私鑰、助記詞與資料庫密碼不進資料庫，也不進前端環境變數。

尚未完成：Redis 工作佇列、物件儲存的簽章網址、多台伺服器共用的 nonce 儲存，以及 Prisma 交易。

## 模型與網站

模型行程沒有簽章金鑰。網站只要求錢包簽名與公開的合約讀取，不索取私鑰。餘額只在合約地址已設定時從 Sepolia 讀取。

## 舊部署

Sepolia 上的 `0x444696e8926BBfce3B04B288D7983F286EC8B814` 是舊的克數合約。新介面與它不相容。不要把新錢包的質押地址指到那份合約。
