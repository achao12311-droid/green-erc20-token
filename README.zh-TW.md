# EcoToken

ECO 是一本公開的帳本。它記下每個人有多少 ECO。全部加起來不能超過 1,000,000 個。沒有人能把所有轉帳關掉。

新的 ECO 要先有一份重量紀錄，再由指定的人簽名承認。每 1,000 克增加 1 個 ECO。申請的人不能自己把數量填大。同一份紀錄只能用一次。

第 1 號紀錄在 [records/action-1.csv](records/action-1.csv)，說明在 [records/action-1-method.txt](records/action-1-method.txt)。那是一張 A4 紙，依紙張尺寸算出 4.9896 克，合約用整數，所以記成 5 克，可以增加 0.005 個 ECO。這不是秤出來的重量。

簽名時，錢包會顯示：要給誰、第幾號紀錄、多少克、到期時間，以及說明檔的指紋。指紋是那份說明的 `keccak256`。鑄幣之後，合約把指紋存在 `recordHashes`。別人可以拿說明檔再算一次，看是否同一個指紋。簽名過期、用過，或不是簽給這一份程式，都不會增加 ECO。

把 ECO 直接轉進這份程式會失敗。要鎖起來，只能用 `stake`。要拿回來，用 `unstake`。送給別人用 `transfer`。若要讓別人來拿，先 `approve`，再由對方 `transferFrom`。

換簽名的人要兩步：現在的人先提名下一位，下一位自己接受之後才生效。

部署時一開始發出的數量必須少於 1,000,000，後面的簽名紀錄才還鑄得出新幣。這個倉庫沒有私鑰，也還沒有公開網路上的地址。
