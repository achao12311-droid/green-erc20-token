# Green Eco Token（ECO）

這份說明與 [README.md](README.md) 相同，都是繁體中文。

ECO 是一本公開帳本上的代幣，總量不能超過 1,000,000 枚。想增加新的 ECO，必須先有一筆環境活動提交、人工核准，以及證明人的簽名。簽名過期、用過，或不是簽給這條鏈上的這份合約，都不會增加代幣。

分數稱為 Eco Points。它只是內部記分。目前沒有確認 1 分等於多少 ECO，因此系統不會自動鑄幣，也不會宣稱這些分數代表多少減碳或清運量。

把 ECO 鎖起來使用質押合約。鎖起來的數量可以原數取回，沒有利息。這不是把錢拿去幫以太坊產生區塊。

通過審核的環境行為會依獎勵表得到 ECO。ECO 可以拿來買抽獎券。活動取消才退票；完成之後票錢不退。CS2 皮膚由主辦者交給得主，不會由合約發送。公開網路的開獎還要接 Chainlink VRF。

先打開桌面 ECO Wallet 並解鎖，網站再按 ECO Wallet，就會連到這台電腦上的錢包。ECO 可以轉給任何地址，對方不用先同意，也能轉進來。不能轉進代幣合約自己。兩邊都不會向你索取私鑰。

歷史上的克數紀錄仍留在 `records/`，但已經廢止，不再用來計算 ECO。

安裝、測試與 Sepolia 的步驟見 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。
